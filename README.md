# ChitChat

A privacy-first messaging app built Android-first with Expo and React Native.

## Product direction

ChitChat combines end-to-end encrypted conversations with recipient-controlled secret-message reveal. Text and selected media can be concealed and revealed with a playful animation, or revealed manually according to recipient preferences.
